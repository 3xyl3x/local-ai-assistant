# Gruppträning

Pulsverket erbjuder gruppträning för
olika träningsnivåer.

## Veckoschema

| Dag | Tid | Pass |
|---|---|---|
| Måndag | 07.00 | Spinning |
| Måndag | 12.00 | Rörlighet |
| Måndag | 18.00 | Styrka Mix |
| Tisdag | 09.30 | Seniorcirkel |
| Tisdag | 17.00 | Ungdomsträning 13–14 år |
| Tisdag | 18.00 | Pilates |
| Onsdag | 12.15 | Yoga |
| Onsdag | 18.00 | HIIT |
| Torsdag | 06.30 | Spinning |
| Torsdag | 17.30 | Funktionell träning |
| Fredag | 11.00 | Core |
| Fredag | 16.30 | Styrka Mix |
| Lördag | 10.30 | Bootcamp |
| Söndag | 16.00 | Yoga |

Alla pass är 45 minuter, utom Yoga och
Pilates som är 60 minuter.

## Bokningsregler
- Bokning öppnar 7 dagar före passet.
- Avbokning måste göras minst 2 timmar före.
- Incheckning krävs senast 5 minuter före start.
- Vid fullt pass erbjuds väntelista.
- Två oanmälda frånvarotillfällen inom 30 dagar
  medför 7 dagars bokningsspärr.

## Gruppträning med dagkort
Dagkort ger tillgång endast till pass
som avslutas senast 14.00.

## Passbeskrivningar

### Spinning
Konditionsträning på stationära cyklar.
Deltagaren reglerar själv motståndet.

### Seniorcirkel
Lågintensiv cirkelträning med fokus på
styrka, balans och rörlighet.
Passet är öppet för alla vuxna.

### HIIT
Högintensiv intervallträning.
Rekommenderas för deltagare med
viss träningsvana.

### Yoga
Lugn träning med rörlighet,
andning och balans.

### Styrka Mix
Helkroppsträning med vikter och
funktionella övningar.

### Ungdomsträning
För barn 13–14 år.
Leds alltid av instruktör.
Kräver separat föranmälan och
vårdnadshavares godkännande.
Ingår inte i vanliga gymmedlemskap.
Kostar 90 kr per tillfälle.
